PlaceCell navigation architecture

User instruction
Text or transcript

“Go to the printer, then visit the cupboard.”

Planning agent

Interpret the request and context.
Propose ordered destination descriptions.

Plan review agent

Check intent, order and constraints.
Approve, clarify or reject the plan.

Approved plan

Mission controller

Execute one goal at a time

Owns goal order, localization checks, timeouts and cancellation.

Retrieve

Find candidates in current visual and object memory.

Inspect images

A vision model checks saved images against the goal.

Navigate

Nav2 drives to the checked destination pose.

Verify arrival

Fresh camera evidence checks the requested destination.

Ambiguous candidate

Ask for a selection before driving.

Verified arrival

Start the next goal, or finish.

Failed or unverified

End the sequence; never skip ahead.

Visual & object memory

Images, captions, object IDs, poses and times.
Camera observations continue during motion.

Supports retrieval and arrival verification.

Conversation context

Saved prompts, reviewed plans and outcomes.
History survives restart; movement does not replay.

Supports planning, review and follow-up requests.
