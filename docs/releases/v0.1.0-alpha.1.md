# PlaceCell v0.1.0-alpha.1

The first public alpha release of PlaceCell brings natural-language robot navigation,
persistent visual memory, and optional multi-agent mission planning into a versioned
snapshot for evaluation and integration.

This is an experimental prerelease. APIs and storage formats may change, and real-model
mission accuracy and hardware reliability still need evaluation.

## Included

- **Single and chained destinations:** a planning agent proposes ordered visits, a separate
  review agent checks the plan, and a mission controller executes accepted goals through Nav2.
- **Visual memory:** independent image and caption embeddings, retrieval by meaning, time
  and map position, and persistent SQLite state with a LanceDB vector index.
- **Destination verification:** saved candidate images are checked before navigation, ambiguous
  matches require selection, and fresh camera evidence verifies arrival at memory destinations.
- **Object memory and maintenance:** optional RGB-D object identities and measured geometry,
  repeated-observation reinforcement, corrections, caption refinement, consolidation and retention.
- **Context and feedback:** persistent conversation history, per-goal and mission status on
  `/placecell/navigation_status`, and cancellation that stops the remaining sequence.
- **Development and evaluation:** a robot-independent Python core, retrieval and object-memory
  evaluators, and a bundled Gazebo office with sensor, motion, localization and Nav2 checks.

## Install

Requires Python 3.10 or newer. This release is distributed through GitHub; the package
has not been published to PyPI.

For the full repository, including documentation and simulation:

```bash
git clone --branch v0.1.0-alpha.1 https://github.com/sabeeh-saad/placecell.git
cd placecell
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

For the standalone Python library, download the wheel attached to this release and install it:

```bash
python -m pip install ./placecell-0.1.0a1-py3-none-any.whl
```

The Python package version is `0.1.0a1`, corresponding to Git tag `v0.1.0-alpha.1`.
The wheel and Python source distribution contain the library; use the repository checkout
or GitHub's source archives for the simulation and complete documentation.
`SHA256SUMS` contains checksums for both attached Python distributions.

See the [navigation setup](https://github.com/sabeeh-saad/placecell/blob/v0.1.0-alpha.1/docs/navigation.md)
for ROS 2, Nav2, optional dependencies and model-provider configuration, and
[agent missions](https://github.com/sabeeh-saad/placecell/blob/v0.1.0-alpha.1/docs/missions.md)
to enable experimental mission planning. ROS 2 users need a Python interpreter compatible
with their sourced ROS distribution.

## Validation

- Automated lint, formatting, strict type checks and regression tests on Python 3.10, 3.11 and 3.12.
- A 721-test regression suite; the local full-suite run reached 95.35% coverage.
- Gazebo integration checks for sensors, movement, command timeout, localization and planned navigation.
- Wheel and source-distribution metadata checks, plus installation and offline retrieval from the built wheel.

The recorded visual-memory demonstration covers a single printer destination. Regression
tests use controlled models and transport; the Gazebo CI job does not measure hosted-model
accuracy or chained-mission reliability.

## Current scope

- Navigation requires a known, versioned map, external localization, timestamped observations
  and an existing Nav2 stack.
- Instructions are text or completed speech transcripts. Reference-image prompts, gestures,
  conditional missions and manipulation are outside this release's mission interface.
- Lookalike objects, occlusion, stale evidence and model errors can produce an ambiguous or
  unverified result. A failed or unverified step ends the mission without skipping ahead.
- Configured named places use Nav2 completion; visual arrival verification applies to memory goals.
- Conversation history survives restart; movement is never automatically replayed.
- Back up existing persistent memory collections before evaluating this alpha release's schema upgrades.

Please report issues with the release version, Python/ROS versions, model configuration
and a minimal reproduction. See the
[changelog](https://github.com/sabeeh-saad/placecell/blob/v0.1.0-alpha.1/CHANGELOG.md)
for the detailed implementation history.
